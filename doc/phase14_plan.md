# Phase 14: 對外開放測試準備與編輯器優化 (Completed)

為了在您的自架伺服器 (NUC) 上對朋友們開放測試，我們成功將單機版架構升級為「支援多人連線與資料保護」的伺服器版，並深度優化了和弦編輯器。

## 已完成的開發項目 (Completed Changes)

### 1. 邀請碼註冊與登入機制 (Auth)
- **`frontend/login.html`**: 新增玻璃擬物風格的登入/註冊頁面。
- **邀請碼防護**: 預設邀請碼為 `LiveChordAlpha`。可以建立 `data/config.json` 寫入 `{"invite_code": "自訂密碼"}` 覆寫，並且已將 `data/config.json` 加入 `.gitignore` 確保密語不會外洩。
- 完善的路由保護，所有頁面包含 `/admin` 與背景掃描 API (`/api/auto/start`) 皆受登入身分與權限保護。

### 2. 多使用者資料隔離設計與 Admin 管理員
- **資料隔離**: 將 `favorites.json`、`recent.json` 以及人工修正樂句 `human_sections` 改由 `data/users/<username>/` 資料夾獨立存放，實現每位使用者的資料互不干擾。
- **管理員特權 (Admin)**: 在資料庫建立時，**第一位註冊的使用者**將自動被賦予最高權限 (`is_admin=1`)。首頁會對管理員解鎖「管理後台」按鈕，並獲得自動轉檔背景工作器的操作權限。

### 3. 個人標註資料匯出與備份 (Data Export)
- **一鍵備份**: 在首頁導覽列新增匯出按鈕，一鍵從 `/api/export-data` 下載個人資料庫打包 (`.zip`)，包含播放清單及所有手動調整過的 Ground Truth 標準答案。

### 4. 和弦編輯器極限優化
- **顯微鏡縮放 (Zoom)**: 時間軸最大縮放放大至 150，並支援 localStorage 持久化記憶，換歌免重拉。
- **倒退與快進**: 支援畫面按鈕及鍵盤 `←` / `→` 進行 5 秒跳轉，並克服了暫停時畫面不同步的問題。
- **新增進階和弦面板**: 增補了 `aug`, `dim`, `sus2`, `sus4`, `m7b5`, `maj9` 等常用調色盤按鈕。
- **網格貼齊 (Snap to 0.25s)**: 解除 30px 長度封印，並實作打勾啟用的網格吸附功能，一鍵精準對齊音樂節拍。
