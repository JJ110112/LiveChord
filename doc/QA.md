## 1. 測試策略

| 測試層級 | 範圍 | 工具 |
|----------|------|------|
| 單元測試 | 和弦轉換、搜尋邏輯、資料解析 | pytest |
| API 測試 | 所有 REST endpoint | pytest + httpx (FastAPI TestClient) |
| 前端測試 | 手動測試 + 瀏覽器 DevTools | Chrome/Edge |
| 整合測試 | 端對端播放流程 | 手動驗收 |
| 效能測試 | 搜尋回應時間、串流延遲 | 瀏覽器 DevTools Network |

## 3. 安全性檢查

| # | 項目 | 檢查內容 | 通過 |

## 4. 效能基準

| 指標 | 目標值 | 測量方式 |
|------|--------|----------|
| 首頁載入 | < 1 秒 | 瀏覽器 DevTools |
| 搜尋回應 | < 200ms | API response time |
| 音訊首次播放 | < 1 秒 | 從點擊到出聲 |
| 目錄瀏覽 | < 500ms | API response time |
| 音樂庫全掃描 | < 5 分鐘 (78K tracks) | 伺服器 log |
| 記憶體使用 | < 500MB | 伺服器監控 |

---

## 5. 已知限制

| 項目 | 說明 |
|------|------|
| FLAC 播放 | Safari 不支援 FLAC，僅支援 Chrome/Edge/Firefox |
| NAS 離線 | Z:\ 不可用時，應顯示友善錯誤訊息 |
| 並行寫入 | JSON 檔案不支援並行寫入鎖（私人用途可接受） |
| 全庫掃描 | 首次掃描耗時較長，後續增量更新 |

---

## 6. 缺陷分級

| 等級 | 定義 | 處理時限 |
|------|------|----------|
| P0-Critical | 無法播放音樂、資料遺失 | 立即修復 |
| P1-Major | 功能異常但有替代方案 | 當次 Phase 內修復 |
| P2-Minor | UI 瑕疵、非核心功能異常 | 下次迭代修復 |
| P3-Enhancement | 改善建議 | 排入 backlog |

---

## 7. 驗收流程

1. 開發完成後，逐項執行上述測試清單
2. 所有 B-xx、F-xx、P-xx 項目通過 → Phase 通過
3. S-xx 安全性項目全數通過
4. 效能指標達標
5. 記錄測試結果與發現的問題
