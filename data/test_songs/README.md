# 和弦偵測測試曲目

分級驗證和弦偵測準確度。每個階段需通過驗證才能推進下一階段。

## 目錄結構
```
test_songs/
├── Lv1/    三和弦流行曲（入門）
├── Lv2/    七和弦流行/R&B
├── Lv3/    爵士標準曲
├── Lv4/    複雜爵士/Fusion
└── Lv5/    高難度：轉調/變拍/Modal
```

## 驗證方法
1. 對每首測試歌曲執行 `python chord_detect.py <file>`
2. 將結果與 Chordify / 樂譜網站 比對
3. 以「正確率」衡量：正確和弦數 / 總和弦數
4. 每首歌的 expected_chords 已列在各級 criteria.txt 中

## 通過標準
| 級別 | Key 正確率 | 和弦正確率 | 說明 |
|------|-----------|-----------|------|
| Lv1  | 100%      | ≥ 80%     | 基本三和弦必須穩定辨識 |
| Lv2  | 100%      | ≥ 70%     | 七和弦辨識 + 時間對齊 |
| Lv3  | ≥ 80%     | ≥ 60%     | ii-V-I 進行辨識 |
| Lv4  | ≥ 70%     | ≥ 50%     | 複雜和聲 + 轉調 |
| Lv5  | ≥ 60%     | ≥ 40%     | 極難：Modal / Free |
