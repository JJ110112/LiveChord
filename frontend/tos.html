LiveChord Terms of Service

1. About this service

LiveChord is a music chord analysis and learning tool. The current build offers:

  • Browse the existing chord database (54,000+ songs)
  • Upload an audio file for automatic chord detection
  • Extract chords from a YouTube URL

2. How we handle uploaded audio

  • Uploaded audio is used only for chord analysis and deleted right after僅用於和弦分析，處理完畢後立即刪除
  • Audio is retained for at most 10 minutes, then automatically purged
  • We do not keep any audio file copies on the server
  • Only analysis results (chord progressions, key) are kept

3. Usage limits

  • Each user may process at most 10 new songs per day
  • Single-file upload size limit: 200 MB
  • This service is for personal music study only個人音樂學習用途

4. How we use the data

  • Generated chord data may be used to improve service quality
  • Anonymous usage stats help us understand which features people use
  • Personal information is never shared with third parties

5. Disclaimer

  • Chord analysis is AI-generated; accuracy may be limited
  • The service may be unstable; uptime is not guaranteed
  • Users are responsible for ensuring uploaded content complies with local law
